# next-eldesquite

Sitio literario de **El Desquite** (Garitma), construido con Next.js y Aura Design System.

## Prerequisites

- Node.js 20+
- [pnpm](https://pnpm.io)

## Getting started

```bash
pnpm install
pnpm preflight
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js App Router
- Tailwind CSS v4 + Aura (13px spacing, 12-step color scales)
- Wiki: `wiki/obsidian-eldesquite` · Bruno: `wiki/bruno-eldesquite`
